# AI Tech Consultant

An AI-powered project designed to help users find information from a product knowledge base and build intelligent workflows.

## Project Tasks

### Task 1: The Knowledge Brain
- Ingest help-center articles from a sitemap.
- Extract and organize article content.
- Retrieve relevant information and provide source links.
- Expose functionality through an API.

### Task 2: Inbox Agent
- Build an inbox assistant using the Knowledge Brain API.

### Task 3: Meeting to Scope
- Build a tool that converts meeting information into a structured scope using the Knowledge Brain API.
